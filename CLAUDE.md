# Working in this repo

See `README.md` for layout and build commands, `SPINE.md` for the lecture-deck structure rules, and `book/src/introduction.md` for the course's Class Format.

## Style rules

- **No em dashes (—)** in slide decks (`slides/`) or the hands-on lab book (`book/src/`), including embedded SVG diagram text. Use a plain hyphen with spaces instead (` - `), matching the existing convention throughout both - e.g. "Fa0/0 = FastEthernet0/0, the router's first FastEthernet interface - Cisco's interface-naming shorthand." This applies to prose, captions, and diagram labels alike.
- No decorative arrows (`→`, `->`) in slide or chain-document prose (see `SPINE.md`) - Mermaid diagram syntax and the book's UI click-path breadcrumbs are exempt.
